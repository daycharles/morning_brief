# ADR-001 — Weather API Selection: Open-Meteo vs OpenWeatherMap

**Date:** 2026-05-01  
**Status:** Accepted

---

## Context

The Morning Briefing System requires a daily weather forecast for Los Angeles, CA (34.0522°N, 118.2437°W) covering High/Low temperatures in °F and precipitation probability. The system targets a zero-friction deployment model where the minimum number of API secrets is required so the workflow runs with minimal prerequisite setup.

---

## Decision

**Use Open-Meteo** (`api.open-meteo.com`) as the primary weather data source.

Open-Meteo provides a free, no-registration, no-API-key REST API that returns JSON forecasts including `temperature_2m_max`, `temperature_2m_min`, and `precipitation_probability_max` in daily forecast arrays. The API supports Fahrenheit as a native unit parameter (`temperature_unit=fahrenheit`), avoiding client-side unit conversion.

---

## Alternatives Considered

| Option | Pros | Cons |
|---|---|---|
| **Open-Meteo** (chosen) | Free, no API key, high accuracy, JSON, supports °F natively | Fewer historical data features |
| **OpenWeatherMap** | Well-documented, widely used | Requires `OPENWEATHER_API_KEY` secret; free tier has rate limits |
| **Weather.gov (NWS)** | Free, official US data, no key | Complex XML/GeoJSON format, two-step geocoding lookup, slower |
| **WeatherAPI.com** | Simple JSON | Requires API key; free tier limited |

---

## Consequences

- **Zero secret overhead** for weather: the workflow runs with no `OPENWEATHER_API_KEY` configured.
- **No rate-limit risk** on free tier: Open-Meteo has generous public quotas suitable for one call per day.
- Open-Meteo is treated as the single weather source; the `weather_fetcher.py` module optionally falls back to OpenWeatherMap if `OPENWEATHER_API_KEY` is present in the environment.
- Open-Meteo's API stability and uptime become a dependency; monitored via graceful degradation (failed FetchResult if unreachable).

---

## Notes

- Open-Meteo endpoint: `https://api.open-meteo.com/v1/forecast?latitude=34.0522&longitude=-118.2437&daily=temperature_2m_max,temperature_2m_min,precipitation_probability_max&temperature_unit=fahrenheit&timezone=America%2FLos_Angeles&forecast_days=1`
- If `OPENWEATHER_API_KEY` is set, `weather_fetcher.py` MAY use it as an alternative source with a feature flag — this is an optional enhancement, not a requirement.
- Open-Meteo returns the `daily` array for the current day at index `[0]`.
