# ADR-002 — News API Selection: NewsAPI vs Alternatives

**Date:** 2026-05-01  
**Status:** Accepted

---

## Context

The Morning Briefing System requires the top 5 current US national political headlines, each with a title, source name, published date (YYYY-MM-DD), and URL. The solution must support a single API call per day from GitHub Actions. A developer-accessible free tier is required; the API must return structured JSON that is easy to parse without scraping.

---

## Decision

**Use NewsAPI** (`newsapi.org`) with the `/v2/top-headlines` endpoint filtered for US political headlines.

NewsAPI provides a well-documented REST JSON API returning structured article objects that include `title`, `source.name`, `publishedAt`, and `url` fields — exactly matching report requirements. The query parameters `country=us`, `category=general`, `q=politics`, `pageSize=5`, `language=en` produce the desired result set in one HTTP GET.

---

## Alternatives Considered

| Option | Pros | Cons |
|---|---|---|
| **NewsAPI** (chosen) | Structured JSON, US political filter, 100 req/day free, widely used | Requires `NEWSAPI_KEY` secret; developer plan only for production |
| **GNews API** | Simple REST JSON | Fewer results on free tier (10/day); less US political relevance |
| **RSS scraping** (e.g. Google News RSS) | No key required | Brittle XML parsing; format changes break integration; inconsistent metadata |
| **MediaStack** | JSON, free tier | Less popular; political category filter less refined |
| **The Guardian API** | Free, good metadata | UK-centric; US political coverage is secondary |

---

## Consequences

- **Requires `NEWSAPI_KEY` GitHub Secret**: administrators must configure this before the workflow runs.
- **Free tier: 100 requests/day** — more than sufficient for a single daily run; no rate-limit risk under normal operation.
- HTTP 429 from NewsAPI is handled per EC-001: logged as `failed/rate-limited`, section skipped, workflow continues.
- The `news_fetcher.py` module uses `pageSize=5` to guarantee exactly 5 headlines (AC-004); if the API returns fewer, the fetcher renders what is available rather than failing.

---

## Notes

- NewsAPI endpoint: `https://newsapi.org/v2/top-headlines?country=us&category=general&q=politics&pageSize=5&language=en`
- Authorization header: `X-Api-Key: {NEWSAPI_KEY}` (do not log the key value).
- `publishedAt` is ISO-8601; the fetcher formats it as `YYYY-MM-DD` for the report.
- If `NEWSAPI_KEY` is absent at startup, the News section will render as failed with message `"NEWSAPI_KEY not configured."` — partial report (AC-010) still generated.
